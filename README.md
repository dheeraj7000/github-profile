### 📌 Featured Project

**[Experience Engine](https://github.com/dheeraj7000/experience-engine)** — a
continual-learning research prototype for LLM agents. Turns an agent's past
trajectories into validated, reusable competence (record → evaluate →
diagnose → induce → validate on held-out → update policy) instead of just
retrievable memory, benchmarked against a stateless and a memory-only
baseline on execution-graded QA tasks.
